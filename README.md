# Giant Explorer

Giant Explorer 是一款 Android 文件管理器，用于浏览本地文件、访问其他应用提供的文档目录，以及管理远程服务器上的文件。支持插件扩展和多窗口操作。

## 功能

- 文件管理：复制、移动、删除、查看属性、新建文件和文件夹，以及预览压缩文件。
- 浏览方式：列表与网格视图，按名称、大小或时间排序，过滤隐藏文件；界面跟随系统切换浅色与深色主题。
- 文档访问：通过 Android Documents Provider 访问其他应用提供的文件，使用系统目录选择器授权。
- 远程访问：FTP、SFTP、FTPS（显式和隐式）、SMB 与 WebDAV。
- 插件扩展：图片浏览、ZIP 解压缩等功能，详见下方插件说明。
- 多窗口：普通窗口、分屏和自由窗口模式，支持粘贴与拖拽前确认。
- 其他入口：后台任务管理、存储管理和 root 权限检查。

## 安装与开始使用

需要 **Android 8.0（API 26）或更高版本**。

1. 从本仓库 GitHub Actions 中成功的 Release 工作流下载 `giant-explorer-release` 构建产物，解压后在 Android 设备上安装其中的 APK。
2. 打开应用，按提示授予文件访问权限；可通过「管理权限」入口调整授权。
3. 浏览本地目录，使用文件操作菜单复制、移动、删除文件或查看属性。
4. 访问其他应用的文档目录时，在侧边栏选择对应来源，再通过系统目录选择器选择并授权目录。

访问范围和可执行的操作取决于系统权限、文档提供方或远程账户的权限。普通文件管理不需要 root；「root 访问」入口可用于检查设备的 root 权限。

## 远程连接

在主菜单打开「远程访问」，添加连接并选择协议，填写服务器、端口、用户名和密码；SMB 还需要填写共享名称。可以先点击「测试连接」，确认成功后保存，再从侧边栏选择已保存的连接浏览文件。

FTPS 提供显式和隐式两种选项，请使用与服务器配置一致的模式和端口。

## 插件

| 插件 | 用途 | 形式 |
| --- | --- | --- |
| Li | ZIP 解压缩 | Shell GEP 插件，操作入口加入文件菜单 |
| Yue（阅） | 图片浏览 | Fragment GEP 插件，也有独立应用 |
| Yue HTML | 图片浏览与缩放 | HTML 插件包 |

在「插件管理」中点击添加按钮，选择插件包并导入，再刷新插件列表查看插件。插件操作会根据所选文件显示在文件菜单中。

当前插件扫描只识别 `.apk` 和 `.zip` 文件，而 GEP 加载器按 `.gep` 扩展名识别原生插件。因此，当前版本导入 `.gep` 后不会被列表扫描发现；发布流程产出 GEP 并不代表宿主的导入流程已经完整支持它。

更多插件说明见 [插件文档](plugins/README.md) 和 [Yue 文档](plugins/yue/README.MD)。

## 窗口与操作设置

在「设置」中选择「打开新窗口的模式」，然后通过主菜单的「新建窗口」打开窗口。

| 模式 | 行为与限制 |
| --- | --- |
| `normal` | 默认模式，打开普通的新窗口任务。 |
| `split` | 请求在相邻分屏中打开窗口；能否从全屏直接进入分屏取决于 Android 版本和设备实现，较旧系统通常需要先手动进入分屏。 |
| `freeform` | 请求按指定窗口边界打开；需要系统支持自由窗口，选择时若系统未声明支持，应用会显示提示。 |

这三种模式是单选设置。应用不会按系统版本禁用某个选项，实际表现取决于设备厂商的窗口管理实现。

「粘贴和拖拽之前需要手动同意」默认开启，可在设置中调整。

## Content Provider 兼容性

应用会暴露 Content Provider，对应的 URI 资源也可能来自另一个应用的 Content Provider。

这种转发在部分设备上可能无法正常工作，原有授权也可能失效。即使可以正常访问，`canRead` 的鉴权结果仍可能不准确；原有实现并不依靠该结果阻止使用。遇到权限问题时，可尝试重新通过系统目录选择器授权。
